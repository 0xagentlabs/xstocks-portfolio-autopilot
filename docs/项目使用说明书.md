# xStocks Portfolio Autopilot 项目使用说明书

## 范围与架构

本项目交付 Phase 0–2 的安全基础：Pinocchio 链上策略配置/状态机/幂等执行审计，以及钱包签名的 Next.js Dashboard。`program/` 是合约，`dapp/` 是前端，`docs/ABI.md` 是唯一 ABI 规范。自动 DEX swap、托管 scheduler 与主钱包私钥存储不在本版本中；Quote/Oracle 异常必须 fail closed。

## 环境与启动

需要 Rust 1.89+、Solana CLI 4.2+、Node 22+、pnpm 11+。先执行 `cargo build-sbf`，再执行 `cargo test --workspace`（LiteSVM 会加载刚生成的 `.so`）；前端执行 `cd dapp && pnpm install --frozen-lockfile && pnpm test && pnpm exec tsc --noEmit && pnpm build`。本地启动用 `pnpm dev`。钱包网络选择 devnet，RPC 为 `https://api.devnet.solana.com`。

## 地址与账户

Program ID 为 `6Uzr4jz1SENxn3DdprQQ24zxaJXr6rThQNB48QxbuJed`。Portfolio PDA seeds 为 UTF-8 `portfolio` + 钱包公钥；每个钱包一个 160 字节账户。字段、指令 tag、账户顺序、错误码详见 `docs/ABI.md`。

## 页面操作

连接钱包后 Dashboard 回读对应 PDA，展示配置版本、状态、风控和模拟资产分配。Portfolio/Strategy/Trades/Settings 导航为 MVP 信息架构预览。链上已有 Portfolio 时，Run、Pause、Emergency stop 分别提交状态 1、2、5；按钮会等待签名和 confirmed 确认。按钮仍受链上状态转换表约束。停止是不可恢复终态，只禁止新执行，不卖出已有资产。

## 链上查询与部署

用 `solana config get` 确认 devnet，`solana program show 6Uzr4jz1SENxn3DdprQQ24zxaJXr6rThQNB48QxbuJed --output json` 查询程序，`solana account <PORTFOLIO_PDA> --output json` 回读状态。升级现有 devnet 程序使用 `solana program deploy target/deploy/xstocks_autopilot.so --program-id 6Uzr4jz1SENxn3DdprQQ24zxaJXr6rThQNB48QxbuJed --url devnet --output json`。首次初始化使用 `cd dapp && pnpm init:devnet -- ~/.config/solana/id.json`；仅可在 Draft 状态运行的完整验证使用 `pnpm lifecycle:devnet -- ~/.config/solana/id.json`，它最终会不可逆地进入 Stopped。program keypair 受 `.gitignore` 保护，绝不可提交或展示私钥。主网只允许需求方按 `docs/MAINNET_RUNBOOK.md` 自行操作。

## 策略与风控

权重用 basis points 表示且有效资产之和必须为 10000；core ratio 不超过 10000；rebalance band 不超过 50%，slippage 不超过 10%，daily trades 必须大于 0。只有 Running 可记录 execution，execution_id 必须严格递增。RecordExecution 的 input/output/fee/NAV 必须使用同一估值单位；链上执行 output 非零、fee、slippage、UTC 日交易数和日换手率限制。生产执行服务仍须验证 oracle/TWAP、DEX quote 真实性、token decimals 归一化、price impact、真实余额、每日损失和授权程序白名单，详见 `docs/ABI.md`。

## 排错与安全

`BadPda` 表示 seeds/bump 不匹配；`Unauthorized` 表示 authority 未签名或与状态不符；`DuplicateExecution` 表示 execution id 已使用；`InvalidStatus` 表示状态转换非法或非 Running 时记账；`RiskLimitExceeded` 表示 slippage/日交易数/日换手率越界。RPC 超时不可自动假定失败并重复交易，应先按签名查询确认。本项目从不接收主钱包私钥。
