# xStocks Dev Path 项目使用说明书

## 项目简介与范围

本项目交付一份中文 Solana xStocks 工程路线图网页，覆盖 13 周核心路径：资产与 Token-2022 基础、组合数据层、报价交易、Pinocchio 自动化、行情风控、测试审计与渐进上线。路线图包含 6 个阶段、18 个模块、上游文档入口及每阶段退出门禁；内容仅供开发规划，不构成投资建议。

仓库中的 `program/`、`docs/ABI.md`、`dapp/lib/program.ts` 和测试是第 4 阶段可运行参考实现，并未因路线图页面而删除。

## 架构与目录

- `dapp/app/page.tsx`：路线图内容、筛选交互、文档链接和移动导航。
- `dapp/app/globals.css`：设计 tokens、响应式布局、焦点与 reduced-motion 规则。
- `program/`：Rust + Pinocchio 策略状态程序参考实现。
- `docs/ABI.md`：链上程序 ABI；路线图本身没有链上指令。
- `dapp/lib/program.test.ts`：ABI 编码与 PDA 客户端测试。

## 环境、安装与启动

需要 Node.js 22+、pnpm 11+。若继续开发参考合约，还需 Rust 1.89+ 与 Solana CLI 4.2+。

```bash
cd dapp
pnpm install --frozen-lockfile
pnpm test
pnpm dev
```

浏览器打开 `http://localhost:3000`。生产构建运行 `pnpm build`。

## 页面使用

顶部导航可跳转“路线图 / 设计原则 / 资源”。“全部阶段、现在开始、随后推进、上线准备”用于筛选阶段；每个模块下方按钮打开相应 xStocks、Solana、Jupiter、Pyth 或测试工具文档。移动端使用菜单按钮展开导航，键盘用户可通过页首“跳至路线图”链接直接进入主体内容。

推荐按序执行，每一阶段的 `EXIT GATE` 通过后再进入下一阶段。尤其需要先验证 xStocks 官方 mint 和 multiplier，再进行估值或交易集成。

```bash

```

Vercel 项目 Root Directory 必须是 `dapp`，Install Command 使用 `pnpm install --frozen-lockfile`，Build Command 使用 `pnpm build`。生产部署须由本仓库默认分支的 Git 集成触发。

## 常见问题与安全注意事项

- 页面字体加载失败时会自动回退到系统 sans-serif，不影响内容和交互。
- 外部文档发生迁移时，更新 `dapp/app/page.tsx` 中对应链接并重新执行构建。
- xStocks 在 Solana 上使用 Token-2022 与 Scaled UI Amount；不可将 raw balance 直接当展示数量。
- 未知 mint、过期价格、异常价差或不完整交易模拟必须 fail closed。
- 不在浏览器、日志或仓库中存储私钥；只允许钱包签名。
- xStocks 的司法辖区限制、法律披露和资产列表可能变化，上线前必须从官方资料复核。
